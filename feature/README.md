# 🎨 Clndr Feature Modules (`clndr/feature`)

The `feature` directory encapsulates dynamic feature modules providing distinct user interface screens and widget components for Clndr.

---

## 📂 Feature Module Inventory

```text
feature/
├── lifegrid/              # Life grid visualization screen & progression charts
└── widgets/               # Jetpack Glance home screen calendar & progress widgets
```

---

## 🛠️ Components

- **`lifegrid`**: Implements `YearProgressScreen.kt` visualizing yearly progress bars and milestone indicators.
- **`widgets`**: Implements Glance app widgets (`WidgetUi.kt`) for home screen integration.
